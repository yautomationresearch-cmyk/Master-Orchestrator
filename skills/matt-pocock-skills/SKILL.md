# Matt Pocock Engineering Skills Suite

A unified, full-spectrum engineering methodology designed by Matt Pocock for autonomous AI coding agents.

## Core Capabilities & Workflows

### 1. Requirement Alignment & Grilling
- **grill-me**: Deep question-and-answer interview before writing code to resolve ambiguities and lock down specs.
- **grill-with-docs**: Interviewing the user while automatically maintaining and updating architecture documentation.
- **wait-what**: Pausing execution when encountering an unexpected architectural anomaly or breaking assumption.

### 2. Issue Management & Triage
- **triage**: Systematically categorizing, prioritizing, and labeling tasks, bugs, and feature requests.
- **handoff**: Clean summary protocol for transitioning state or handing over tasks to other agents or sessions.

### 3. Architecture & Documentation
- **adr (Architecture Decision Records)**: Documenting why specific technical choices were made.
- **writing-for-agents**: Producing concise, unambiguous technical markdown for AI consumption.

### 4. Implementation Guidelines
- Reject vague assumptions ("vibe coding") in favor of verified, spec-driven development.
- Maintain minimal verbosity while preserving full technical precision.
- Run tests and verifications before declaring completion.
