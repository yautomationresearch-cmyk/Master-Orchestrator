# Brief intake

**Theme first:** Do not run this intake until the Theme Gallery gate is satisfied ([theme-gallery-gate.md](theme-gallery-gate.md)). Launch the gallery and wait — never substitute a multi-choice “what is this about?” card full of open-file guesses.

## Do not invent topic options from the workspace

Never propose choices like “content from the open X notes”, “convert neuroscience-web-deck”, or any other path pulled from open editors. Those are irrelevant when the user only said “create a PPT.”

Ask for the topic in plain language (or one generic AskQuestion). Examples of **allowed** options if you must use a form:

- I’ll type the topic in chat  
- Board / leadership update  
- Pitch / fundraising  
- Teaching / lecture  
- Other…

## After theme is locked — ask only what changes the deck

Keep it short. Prefer free-text over long quizzes.

### Usually ask

- What should the deck be about? (one sentence is enough to start)
- Who watches it, and what should they decide or learn?
- Rough slide count or minutes?

### Ask only if unclear

- Interactive web deck (default) vs native PPTX?
- Any must-include numbers, brand, or source material? (user will point to files — don’t assume open tabs)

## Safe defaults

- interactive web deck matching the **selected gallery theme**
- 16:9
- 10–15 scenes unless user says otherwise
- keyboard nav; no click-on-slide advance (gallery contract)
- no hosting / deploy unless asked
