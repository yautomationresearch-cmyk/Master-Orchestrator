# Scenario profiles

Choose one primary profile before selecting scenes. Profiles guide decisions; they do not force a fixed visual theme.

## Education / lecture

Goal: make a concept understandable and memorable. Prefer a question-led opening, a scaffold or map, one mechanism close-up, an applied example, a takeaway, and sources. Use progressive reveals and speaker notes. Keep visible copy concise.

## Documentary / biography

Goal: create a credible chronological or causal story. Prefer timeline, archival image, quote/context, consequence, and source scenes. Keep captions and attribution legible. Do not use dashboard-like UI unless the subject requires it.

## Executive briefing

Goal: support a decision quickly. Start with the answer, then evidence, drivers, risks, and recommended action. Prefer statement, metric, comparison, and decision scenes. Avoid decorative imagery that competes with the decision.

## Business pitch

Goal: persuade around a problem, opportunity, solution, proof, and ask. Use a clear narrative spine and one visual claim per scene. Reserve brand color for semantic emphasis and keep the ask explicit.

## Scientific / medical explanation

Goal: distinguish established findings, useful models, and uncertainty. Prefer mechanism, comparison, anatomy/process, application, and sources. Use authoritative sources and avoid simplified one-to-one claims.

## Technical architecture

Goal: explain systems, boundaries, flows, or tradeoffs. Prefer architecture, process, failure mode, and decision scenes. Use diagrams only for real relationships; keep connectors behind nodes and labels.

## Data / report

Goal: communicate a measured result and its implication. Prefer answer-first title, chart, driver breakdown, comparison, caveat, and action. Do not replace evidence with generated decorative imagery.

For Content System **Orbit Data** / **Metric Board** (or clones), follow [data-board-decks.md](data-board-decks.md):

- Metric Board = light only; Orbit Data = dark only (do not mix modes in one sample)
- Recommendation-first spine; fill canvas (no empty lower thirds)
- Recharts + `--chart-*` tokens; pies remount and draw in; absolute scales start at Y = 0
- Scorecard must include KPI tiles + drivers + trend + so-what — not four lonely cards

## Workshop / tutorial

Goal: move the audience through actions. Prefer objective, demonstration, step reveal, practice prompt, checkpoint, and recap. Make the next action visible and use notes for facilitation detail.

## Portfolio / visual story

Goal: create an impression while preserving a coherent arc. Prefer hero, selected work, process, proof, and closing scene. Use larger visual moments but keep navigation and captions restrained.

## Profile selection rule

If the request is ambiguous, infer from audience and goal. If two profiles conflict, use the one that matches the decision the audience must make. State the selected profile in the internal deck brief, not as visible slide copy.
