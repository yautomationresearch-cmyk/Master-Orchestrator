# Scene library

Choose a scene according to the relationship the audience needs to understand. A scene is not a decorative template.

## Scene contracts

### Hero

Use for opening or emotional framing. One large claim, one supporting line, one visual anchor. Avoid lists, grids, and multiple controls.

### Split

Use when text and image need equal importance. Reserve explicit media and copy columns. Keep the image bounded or use a controlled bleed; do not let it collide with the title or footer.

### Map reveal

Use for frameworks, categories, or a sequence. Keep the heading stable and reveal one meaningful item per state. Hidden items must not reserve confusing visual gaps unless the layout requires stable alignment.

### Comparison

Use for two or three concepts that must be distinguished. Use parallel structure, equal visual weight, and a clear axis of comparison. Do not turn every comparison into a card dashboard.

### Process

Use when order and causality matter. Connect steps only when the relationship is real. Create connectors before nodes in SVG/canvas or keep them behind nodes in CSS.

### Image

Use when the image itself teaches. Keep copy short and place it in image negative space or a separate content region. Do not overlay a large paragraph on busy artwork.

### Takeaway

Use for synthesis. Reduce density, return to the central claim, and give the audience a memorable decision rule or question.

### Sources

Use a calm, legible research trail. Sources should be readable at presentation distance; move long URLs or full citations into notes when appropriate.

## Rhythm rules

- Do not use more than two consecutive full-bleed image scenes without a structural or text-led scene.
- Do not use the same scene kind for the entire deck unless the user explicitly asks for a strict template.
- Do not use a five-card grid when a sequence, map, or single composition communicates the idea better.
- Keep the final scene visually quieter than the opening scene.
